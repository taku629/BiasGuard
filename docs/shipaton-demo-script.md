# Shipathon Demo Script (60-120s)

**0:00 - 0:15 | Intro & Problem**
*Visual: Show the app home screen.*
"Welcome to BiasGuard. In today's fast-paced world, unconscious bias in our communication can lead to missed opportunities and misunderstandings. We built BiasGuard to solve this."

**0:15 - 0:45 | Core Demo**
*Visual: Type/paste a sample text into the analyzer.*
"Let's look at how it works. I'm pasting a draft job description here. With one tap, BiasGuard analyzes the text. Look here—it instantly highlights potentially biased language and suggests more inclusive alternatives."
*Visual: Tap on a suggestion and accept it.*
"We've combined our Risk/Behavioral methodology with real-time feedback."

**0:45 - 1:00 | Architecture & Tech Stack**
*Visual: Briefly show a diagram or switch to the history tab.*
"Under the hood, we're using a React Native frontend on Expo, talking to Firebase for auth and real-time data, and custom Cloud Functions that interface with our analysis engine. Subscriptions are powered by RevenueCat."

**1:00 - 1:15 | Conclusion & Call to Action**
*Visual: Show the user profile/premium screen.*
"BiasGuard is ready to scale, helping everyone write with more empathy and clarity. Thank you."
