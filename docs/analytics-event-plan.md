# Analytics & Event Tracking Plan

## Activation Metric
**Metric**: First "Risk Review" Completed.
**Rationale**: Users experience the core value of BiasGuard when they successfully log a trade and view the calculated risk or cognitive bias breakdown for the first time.

## North Star Metric
**Metric**: Weekly Active Risk Reviewers (WARR) - Users reviewing risk and behavior at least once in a 30-day window.
**Rationale**: Demonstrates sustained engagement with the core behavior modification loop, proving that BiasGuard is an ongoing tool, not just a one-time novelty.

## Tracking Events Plan (No SDK Implementation Yet)
* `signup_completed`: Triggered when onboarding is finished.
* `portfolio_synced` / `trade_manually_logged`: User successfully adds initial data.
* `risk_dashboard_viewed`: User accesses the main risk breakdown.
* `bias_insight_read`: User expands or interacts with a specific cognitive bias insight.
* `subscription_paywall_viewed`: Triggered when hitting the Pro tier limit.
* `subscription_purchased`: Conversion to paid user.

## User Research Recruitment Plan
* **Target Size**: 10-20 active traders (crypto or traditional finance).
* **Recruitment Channels**: Reddit (r/Daytrading, r/CryptoCurrency), Twitter/X Finance circles, Discord trading communities.
* **Incentive**: 1-month free premium access or a $20 Amazon gift card.

## Research Sample Structure
* **Beginners (4-6 users)**: Trading < 1 year. Needs basic guidance and simpler UI explanations.
* **Intermediate (6-8 users)**: Trading 1-3 years. Aware of their biases but struggles to correct them. Our core target.
* **Advanced (4-6 users)**: Trading 3+ years. Data-driven, requires deep API integrations and advanced analytics.

## Evidence Ladder
1. **Low**: User survey expressing interest in "psychology tools".
2. **Medium**: Clicking a waitlist or pricing page.
3. **High**: Successfully logging manual trades daily to see risk metrics.
4. **Very High**: Paying for a subscription to unlock unlimited insights.
