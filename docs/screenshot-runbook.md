# Screenshot Runbook

To ensure consistent and high-quality screenshots for the App Store and Google Play, follow this runbook.

## Device Requirements
- **iOS:** iPhone 15 Pro Max (6.7"), iPhone 8 Plus (5.5" - optional but recommended for older device coverage), iPad Pro 12.9" (if iPad supported).
- **Android:** Pixel 7 Pro (or any standard high-res 16:9 / 20:9 device).

## Environment Setup
1. Run the app in a simulator/emulator.
2. Ensure the status bar is clean (100% battery, full WiFi, time set to 9:41).
3. Use test accounts with pre-populated, idealized data (e.g., a history full of successful scans).

## Required Screenshots
1. **Hero Screen:** The main analyzer screen with a text block pasted, showing the "Analyze" button.
2. **Results Screen:** The analyzer screen showing highlighted text and a suggestion card.
3. **History/Stats Screen:** The dashboard showing past scans and risk scores.
4. **Paywall:** The RevenueCat powered premium subscription screen.
5. **Settings/Profile:** The user profile showing account status.

## Processing
- Export as PNG without alpha.
- Do not include simulator chrome (bezels) unless framing them in a marketing template.
