# Shipaton Submission Checklist

- [ ] **Public store URL**: Ensure the app is live and the URL is accessible. (`CHECK_REQUIRED`: App Store/Play Store links)
- [ ] **US downloadable**: Verify the app is available for download in the United States storefronts.
- [ ] **RevenueCat purchase working**: Verify that in-app purchases process correctly in the production environment.
- [ ] **Demo video**: Create and upload a demo video showcasing the core features (risk metrics, behavioral assessment, Pro upgrade). (`CHECK_REQUIRED`: YouTube/Vimeo link)
- [ ] **Screenshots**: Prepare high-quality screenshots highlighting the portfolio, risk analysis, and behavioral insights.
- [ ] **Description**: Write a compelling project description detailing the problem solved and the technologies used.
- [ ] **Public OSS repo**: Ensure the GitHub repository is public, clean, and contains a well-structured README. (`CHECK_REQUIRED`: GitHub URL)
- [ ] **Student eligibility**: Verify that all team members meet the student eligibility requirements for the applicable award tracks.
- [ ] **Deadline**: Confirm the submission is completed before the final deadline.
