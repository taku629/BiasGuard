# Production Release Runbook

1. **Play Console & App Store Connect Checks**: 
   - Verify all metadata, privacy policies, and reviewer credentials are up to date.
   - Confirm target regions and pricing tiers.
2. **RevenueCat**:
   - Ensure products and entitlements are active.
   - Double-check API keys in production environment.
3. **Firebase**:
   - Verify production rules for Firestore and Storage.
   - Deploy production Cloud Functions.
   - Check authentication providers and domain authorized domains.
4. **Stores (Apple & Google)**:
   - Submit for review.
5. **Shipaton**:
   - Verify marketing materials and public web pages are live.
   - Final end-to-end testing post-approval.
